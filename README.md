# 🎮표정게임 (Game Title)

반응형 웹 디자인과 모바일 접근성을 고려하여 제작된 타일/퍼즐 게임입니다.  
다양한 화면 크기에서도 쾌적하게 플레이할 수 있도록 모바일 터치 및 뷰포트 최적화가 적용되어 있습니다.

---

## ✨ 주요 특징 (Key Features)

- **📱 반응형 & 모바일 최적화 (Responsive & Mobile Friendly)**
  - Safe Area(`env(safe-area-inset-safe)`) 대응으로 최신 아이폰 및 안드로이드 기기 지원
  - Dynamic Viewport Units(`dvh`, `vw`) 기반 레이아웃으로 모바일 화면 맞춤
  - 터치 조작 최적화 (`touch-action: none`) 및 사용자 확대 금지 처리
- **📲 홈 화면 아이콘 지원**
  - 홈 화면에 추가할 때 표정게임 아이콘을 표시합니다.
- **🌙 다크 모드 지원 (Dark Mode)**
  - 시스템 테마(`prefers-color-scheme`) 연동 및 `data-theme` 커스텀 속성 지원
- **🎯 직관적인 UI / UX**
  - 진행도 바(Progress Bar), 힌트 시스템, 타이머 및 스코어보드 제공
  - 애니메이션 효과(팝, 쉐이크, 힌트 블링크)를 통한 조작감 향상

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3 (Vanilla CSS with CSS Variables), JavaScript
- **Design System**: Flexbox, CSS Grid, Custom Properties

---

## 🚀 시작하기 (Getting Started)

별도의 설치 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.


## 🧩 게임 규칙 및 조작법 (How to Play)

### 🎯 기본 규칙 (사과게임 방식)
1. **드래그하여 선택**: 보드판 위의 타일을 터치 또는 마우스 드래그로 네모 영역을 만들어 선택합니다.
2. **숫자의 합 만들기**: 드래그로 지정한 영역 안에 들어간 표정들이 **연달아 있는 표정**이 되면 해당 타일들이 제거됩니다.
3. **제한시간 내 클리어**: 상단의 타이머 바가 모두 줄어들기 전까지 최대한 많은 타일을 제거하여 높은 점수를 획득하세요.

---

### 🕹️ 조작법 및 주요 기능
- **터치/드래그 조작**: 모바일 및 PC 환경에서 드래그 제스처로 사각형 드래그 영역을 직관적으로 지정합니다.
- **💡 힌트 버튼 (Hint)**: 같은 표정 조합이 눈에 보이지 않을 때 힌트 버튼을 누르면 제거 가능한 영역을 노란색 테두리로 반짝여 보여줍니다.
- **⚙️ 3단계 난이도 설정 (Difficulty)**: 
  - **쉬움 / 보통 / 어려움** 총 3가지 난이도를 제공합니다.
  - 난이도에 따라 보드 크기, 제한시간, 생성되는 타일의 종류 및 조합이 달라집니다.
